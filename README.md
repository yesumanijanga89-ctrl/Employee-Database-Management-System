# Employee Database Management System

## Project Overview
This project demonstrates an Employee Database Management System developed using SQL. It includes table creation, data insertion, CRUD operations, joins, aggregate functions, views, and database management concepts.

## Technologies Used
- SQL
- PostgreSQL

## Features
- Employee Management
- Department Management
- CRUD Operations
- INNER JOIN
- GROUP BY
- HAVING
- Aggregate Functions
- Views
